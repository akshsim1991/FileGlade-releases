# FileGlade

All your files. One clear view.

FileGlade is a free file manager for Mac and iPhone: one searchable dashboard for your files, folders, cloud folders and drives, with tabs, dual-pane browsing, smart folders, transfers with undo, previews, folder compare and sync, archive browsing and more. Everything happens on your own device, with no account and no tracking.

**Version 3.5.0**

- macOS 13 or later (Apple silicon): [FileGlade-3.5.0-mac.zip](https://raw.githubusercontent.com/akshsim1991/FileGlade-releases/main/FileGlade-3.5.0-mac.zip)

Installed copies find new versions themselves (FileGlade menu > Check for Updates…) and ask whether to update now or later.
